# Casamento

Wedding website built with React, TypeScript, and Vite.

Names, the date, the venue, and the story live in `src/wedding.ts`. Set `dateISO` to a value like `"2027-06-12"` to show the formatted date and a countdown.

```bash
npm install
npm run dev
```

Then open the local URL Vite prints, usually http://localhost:5173.
